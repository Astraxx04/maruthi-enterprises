# Cropped from the brochure pages

The photographs in the parent folder are pages from the Auto Flow brochure: several
products per page, each with its MRP printed beside it. This catalogue does not show
prices, so each product's photograph was cropped out on its own, leaving the price
labels behind. The originals are kept alongside for reference.

`scripts/add-images.mjs` is pointed at this folder, not the parent.
